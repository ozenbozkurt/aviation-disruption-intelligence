# Security Policy

## Supported versions

Security fixes are considered for the latest version on the `main` branch. Older releases are not guaranteed to receive security updates.

## Reporting a vulnerability

Please **do not** open a public issue or pull request that discloses an exploitable vulnerability.

If GitHub's private vulnerability reporting is enabled for this repository, use the **Security** tab and select **Report a vulnerability** to submit the details privately.

If that option is unavailable, contact the maintainer through the contact information on their GitHub profile to request a private reporting channel. Do not include exploit details in a public message.

Please include the affected version or commit, reproduction steps, potential impact, and any suggested mitigation. Reports are reviewed on a best-effort basis; no fixed response or remediation timeline is promised.

## Scope

This project is an analytical prototype, not a safety-certified aviation decision system. Do not use it for dispatch, flight-safety, or go/no-go decisions.
